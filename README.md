# Portfólio

Meu portfólio feito em React para o exercício da EBAC. Ele reúne os projetos que fiz durante o curso, as tecnologias que aprendi e meus contatos.

Feito com React, Vite e CSS Modules.

## Versão online

https://meek-liger-ee53e2.netlify.app

## Como rodar localmente

Precisa ter o Node.js instalado.

```bash
git clone https://github.com/lucassouza88/portfolio_desenvolvedor_front-end.git
cd portfolio_desenvolvedor_front-end
npm install
npm run dev
```

Depois é só abrir http://localhost:5173 no navegador.

## Projetos

- **Micro Cardápio** – sistema de pedidos de restaurante dividido em micro frontends com Next.js e Module Federation.
- **Blog com Next.js** – blog com páginas estáticas e rotas dinâmicas, publicado na Vercel.
- **Lista de Tarefas com Next.js 15** – lista de tarefas com TypeScript, Tailwind e testes com Jest.
- **Pipeline de CI/CD** – site em Next.js com lint, build e deploy automático pelo GitHub Actions.
- **Catálogo de Livros** – CRUD de livros em React com TypeScript consumindo uma API com Axios.
- **Todo React Avançado** – lista de tarefas usando Context API, hooks customizados e useMemo.
- **Diário de Bordo** – PWA que funciona offline e pode ser instalado no celular.
- **Cadastro com Busca de CEP** – formulário que preenche o endereço pela API do ViaCEP.
- **Agência Criativa Web** – site institucional responsivo com SASS.
